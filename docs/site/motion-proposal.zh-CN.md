# 官网动效与交互沙盒

[English](motion-proposal.en.md) · [开发文档](../development.zh-CN.md)

本说明对应已实现的浅色官网展示区。网站使用本地示例数据，不连接 ERP 服务；GitHub Pages 暂不启用。官网展示样式不影响桌面应用。

## 全屏封面与引导线

首屏是独立的 `100svh` 封面，页眉叠放在顶部，保留大标题、说明和两个行动。标题同时按视口宽高适配，较低视口减少上下留白，避免英文说明把滚动入口挤出封面。无脚本时同样保留完整封面和可跳转到业务舞台的滚动入口。

一条青绿细线从按钮下方出发，按滚动位置沿实际弧长伸向入库窗口顶边。封面内容最多上移 28px、缩小 1.8%；停滚即停，倒滚按原路径收回。业务舞台发布与窗口共用的实测投影坐标，封面把页面坐标换算到视口，不猜测窗口落点。舞台进度 8–22% 时引导线淡出，由随后出现的入库→库存→应付来源线接续。手动聚焦、快速跳出场景或端点离开上边界时清除封面路径，避免固定画布在正文上残留旧线。

桌面引导线使用独立、按需初始化的 WebGL 图层，共用业务线的三角带着色器，采用更细、更轻的轮廓与一个随行程移动的端点；WebGL 失效时回退到同一路径的 SVG。手机以 SVG 跟随实际纵向入库窗口，避免增加 GPU 上下文。减少动态及低于 620px 的视口使用静态短线与滚动入口；不移动封面文字，不改变全部业务交互。封面、舞台与后台可见性共同控制按需帧，不建立持续循环。

## 窗口与滚动

三块独立应用窗口保留侧栏、工具条、表格、单层 1px 冷灰细边和有层次的地面灯光。桌面舞台约 340vh，固定展示高度为一个视口；正文大标题随正常滚动退出。窗口位置由统一进度计算，倒滚和直接跳滚均得到同一业务画面，不触发业务操作。

| 进度 | 展示与连接 |
| --- | --- |
| 0–20% | 入库窗口居中，宽度约 85%；库存和财务在右侧不可见且不可聚焦。 |
| 20–38% | 入库缩小左移，库存从右侧进入，形成约 40% / 60% 双屏。 |
| 34–43% | 入库来源锚点向库存流水行绘出第一条连接线。 |
| 38–52% | 双屏稳定，光点到达库存行，保留阅读与操作时间。 |
| 52–70% | 财务从右侧进入，形成方窗—横窗—方窗；投影后宽度约 26% / 47% / 26%，保留间隙。 |
| 66–80% | 第二条线绘向财务来源，随后光点到达应付记录。 |
| 85–95% | 反向光点沿财务、库存、入库回看来源关系。 |
| 95–100% | 保留完整关联，舞台自然离开固定区并进入功能与进度正文。 |

桌面使用原生 WebGL：GPU 绘制漫射光池、冷暖低角度掠光和接触阴影；灯光从投影窗底两端展开，细微地面纹理随光照显现，光场扫动只由滚动进度控制，停滚即停；第二层透明画布绘制青绿连接带和沿线光点。窗口 HTML 与 GPU 采用相同的 1400px 透视距离与窗底投影原点，表单仍是可操作的原生控件。窗框不再叠加静态金属镀层或角部高光，画布不接收指针事件。

三屏总览的入库/库存/财务最小逻辑画布分别为 600×570、1000×585、600×550，窗口整体缩放，桌面侧栏始终保留文字。两侧相反 30°、中窗 4°，近侧顶边明显倾斜，窗底共线；高度由窗口宽高比计算，不绑定整个视口。初始入库为 1100×590，聚焦为 1000px 逻辑宽，按可用高度等比缩小。不再克隆 HTML 内容制作倒影；光池跨度、落点、透明度随同一实体姿态更新，退场窗口不留下光斑。WebGL 失效时保留 CSS 光池，不创建第二份表单。

总览保留单据选择、新建、完整默认单行、合计及复制入口；财务显示来源、应付/已付/未付、关联明细和放大付款入口。详细筛选与付款表单在放大窗口中展示；仅动态桌面财务聚焦采用两列，手机与减少动态效果保持纵向。库存空白占位条只是表格视觉，不表示额外业务记录。

来源锚点先在真实 HTML 逻辑画布中测量，再与窗口共用几何投影；入库线从来源圆点中心出发，库存线连接行边缘，避开数量文字。切换先用约 80ms 淡出旧线，再移动窗口，接近终态时淡入符合条件的线。端点退到屏外、窗口透明度低于 .55、左右顺序交叉或不是同一来源时清除对应路径；放大操作期间不会留下一条横穿舞台的线。筛选使来源行不可见或单据仍是草稿时同样隐藏。SVG 与 WebGL 使用同一组端点与透明度。手机使用 SVG 沿窗口外缘纵向走线，光点不会无限循环。

## 可交互业务

- 采购入库：多张单据、新建草稿、复制草稿、两家供应商、两个仓库、四种物料、多行增删、日期、数量、单价与确认。已确认单据只读。
- 库存：按仓库、物料、来源单号筛选，查看逐笔流水和仓库/物料累计余额；点击来源打开原入库单。来源筛选仅筛流水，余额仍表达当前仓库/物料实际演示结存。
- 财务：按供应商、单号、付款状态筛选；查看来源和物料明细，登记部分付款或付清剩余，保存付款历史。不得超过剩余余额。
- 默认示例 DEMO-001：物料 A，数量 12，单价 ¥10.00，库存 +12，应付 ¥120.00；演示期初库存为 0。
- 草稿不生成库存和应付；确认在一个纯状态转换中完成，禁止重复确认。付款只改变已付、未付与付款历史。
- 数量三位定点小数，单价和付款最多两位小数；逐行金额四舍五入到分再汇总。溢出、无效日期和无效数字均被拒绝，失败不替换旧业务状态。

长记录分页展示：入库和应付明细每页 2 行，库存流水每页 4 行，余额和付款记录每页 3 行。页码属于展示状态，合计、确认和余额始终使用完整业务数据。添加物料打开最后一页；确认时若其他页有错误，自动返回对应页并定位字段。删除或筛选后的越界页会收敛到有效页。桌面先按实际内容（包括展开明细和错误提示）计算逻辑高度，再统一缩放窗口与连线；窗口内不建立滚动容器。总览保留物料、数量和单价，金额列及逐行删除入口在放大窗口中操作。

## 聚焦、滚动优先与状态保存

点击“放大操作”、侧栏或来源链接，目标窗口约 450ms 内放大到舞台约 85% 宽，其他窗口退到两侧，停滚时可以操作。任何页面滚动都会立即取消聚焦、编辑保持与未完成补间，下一帧直接采用真实滚动进度，不等待恢复动画。输入获得焦点仅中止当前放大补间，不阻止滚动。没有暂停或恢复按钮；分步按钮用原生平滑滚动到 10%、45%、80%、92% 的页面位置，“返回总览”滚到 92%，因此滚动条始终与阶段一致。手机与静态模式直接滚到对应窗口。

手动切换预先测量目标内容，只插值已显示与目标的实体位置、尺寸、角度、透明度及舞台高度；过程中固定目标逻辑布局，内部画布随四边缩放，终态恢复等比。避免每帧重排表格与重新适配高度。快速切换接续上一帧实体姿态；编辑可中止放大，页面滚动则立即接管并重新计算当前锚点与地面光场。

手动过渡单帧推进最多 34ms；慢帧时延长行程而不瞬间跳过大段位移。离屏或后台暂停时保留已走时间，回来后从当前姿态接续；正常帧率仍以约 450ms 完成聚焦。后台停帧只用于资源管理，不提供锁定滚动的演示状态。

展示区禁用浏览器滚动锚定，内容高度和聚焦布局变化不自动推移页面的滚动位置。

业务状态存于当前页面内存。同标签页的中英文语言链接通过一次性 sessionStorage 交接，读取后即删除；刷新或重置恢复默认示例。存储不可用时仍可正常切换页面，但演示重新开始。数据恢复校验版本、单据状态、编号、目录值与付款余额。

## 实现边界

| 文件 | 职责 |
| --- | --- |
| `sandbox.mjs` | 纯业务模型、定点金额、库存和应付派生、状态交接校验。 |
| `sandbox-ui.mjs` | 双语 HTML、表单、筛选、记录分页、来源跳转和本地语言交接。 |
| `scene-geometry.mjs` | 顺序布局、逻辑画布尺寸、内容高度适配、窗底投影和 HTML/GPU 共用的纯几何。 |
| `motion.mjs` | 滚动优先、顺序出现、镜头聚焦、连接线与媒体偏好。 |
| `cover-motion.mjs` | 全屏封面、滚动引导、实测入库落点、手机 SVG 与静态回退。 |
| `webgl-stage.mjs` | GPU 漫射光池、掠光、接触阴影、三角带曲线、光点和上下文恢复。 |
| `sandbox.css` | 固定逻辑画布、总览/聚焦、CSS 光池回退、手机及打印。 |

原生 HTML 控件可使用键盘；错误与字段关联，结果通过状态区播报。未出现及退后的窗口不可聚焦。按需 requestAnimationFrame 合并更新；静止、离开场景及切后台不保持连续循环，卸载清理监听器与观察器。

WebGL 仅在桌面动态舞台首次绘制时初始化，像素密度最高 2 倍并受 GPU 渲染缓冲尺寸限制。初始化或着色器编译失败、上下文丢失时立即保留 HTML/CSS/SVG 展示，业务状态不重置；上下文恢复后重建资源并按当前状态请求一帧，卸载释放程序和缓冲区。参考 [WebGL 接口](https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext) 与 [上下文丢失测试扩展](https://developer.mozilla.org/en-US/docs/Web/API/WEBGL_lose_context)。

手机取消固定舞台，窗口纵向排列并随可见性轻微显现；业务功能全部可用，表格改为带字段名的行卡片，使用分页与自然页面滚动，窗口内没有横向或纵向滚动条。减少动态效果取消位移与透视，保留交互和静态来源线。无 JavaScript 时显示静态示例与文档链接，演示控件不承担操作。

低于 620px 的视口高度也取消固定舞台；其中宽度不超过 1000px 的横屏采用手机行卡片，较宽的低高度窗口保留桌面阅读尺寸并纵向排列。切换偏好即使发生在舞台离屏时，也立即清除旧透视尺寸与键盘锁定。

## 验证

地面灯光回归覆盖透视窗底、聚焦/倒滚及宽高变化后的光池落点、退场清理和随滚动变化的光场。控制器测试覆盖编辑或聚焦后立即跟随滚动、快跳、倒滚、后台回到实际进度，以及分步/总览改变真实滚动条。浏览器确认 1505×1045、1280×620、390×844、中英文与减少动态；编辑数量 27.125 后滚动与换语言仍保留草稿，暂停按钮及内容镜像均已移除，灯光边缘无矩形截断，实际内容无内部溢出。

封面引导补充弧长增长、投影坐标平移、聚焦退场、快速跳出清理、后台停帧与 GPU 回退/释放测试。浏览器复查 1505×1045、1280×620、390×844、320×568、844×390，中英文、减少动态与无脚本入口；录制从封面到三窗及倒滚的连续过程，确认引导落在入库顶边、窗口内容无内部溢出，聚焦和快速离场无路径残留。

此次切换修复补充实体姿态接续、屏外/逆向连线、GPU 淡出与旧帧清空、离屏偏好切换、舞台高度预算回归测试。浏览器检查包含三窗连续聚焦、快速分步切换、返回总览、来源跳转、编辑打断、倒滚和恢复；复查 320×568、390×844、844×390、1280×600/620、1015×1039、1366×768 和 2560×1440、中英文、减少动态与无脚本。检查实际内容溢出及顶部/底部位置，并保存连续录屏；视口模拟不代替真实设备验收。

自动测试涵盖跨仓库多物料、逐行舍入、重复确认、只读单据、部分/超额付款、失败状态不变、语言数据恢复、阶段边界、倒滚及直接跳滚、屏上顶边斜率/比例/共同底线、聚焦画布与投影、分页全局行号与完整合计、越界页收敛及内容高度适配。浏览器验收覆盖中英文、1505×1045 对照视口、用户实际 1015×1039 视口、390px 手机、聚焦表单、来源跳转、滚动接管聚焦、减少动态效果与无脚本阅读。最近的细边与无内部滚动检查覆盖 1490×1035、1015×1039、390px、五行物料、跨页错误、四次部分付款、展开明细、键盘操作和语言状态保留；检查真实内容宽高与可用宽高，避免仅隐藏滚动条。此前连续滚动录制保存在任务预览目录，不提交浏览器测试文件。
