# 辅助核算规则

本模块按单公司、人民币提供总账辅助档案、必填规则、余额和来源核对。迁移不推断历史归属，业务子账期初通过独立的[分户期初](subledger-openings.md)逐笔录入并核对。

- 单公司、人民币；客户与供应商复用现有档案，部门与项目由财务维护独立辅助档案。辅助信息不代表多公司权限或完整人事、项目管理。
- 每笔凭证和期初分录最多选择客户、供应商、部门、项目各一个。服务端核验编号，保存名称、编码快照；原始凭证保存、提交、审核及过账均核验科目从启用日起的必填规则和档案状态。
- 科目规则及部门/项目修改使用版本、原因、操作者与前后快照，失败整体回滚。历史分录没有辅助信息时明确显示未分配，不猜测、不重写已过账记录。
- 期初允许同科目按不同辅助组合拆分；相同科目和辅助组合不能重复。正式期初仍须借贷平衡及独立审核；总账试算和公司报表累计全部拆分行。
- 已过账冲销复制原辅助快照；改名或停用不妨碍纠正旧账。业务生成按真实来源带入客户/供应商，部门/项目显式选择，客户端不能改变真实往来对象或金额。
- 损益结转逐个科目和完整辅助组合清零，并按同一组合转入权益。保留来源快照，不因改名、停用或后来增加必填规则而猜测历史归属。
- 辅助余额查询按科目和一个维度汇总，每条分录只累计一次，未分配作为独立分组；返回期初、本期借贷、期末、逐笔来源和同快照 CSV，精确 Decimal 运算。
- 新增查询、配置、档案维护权限；默认管理员与财务员拥有，查看权限不能修改配置或档案。桌面选项沿用建单权限；迟到响应、撤权、保存失败须有明确处理。

验收覆盖：历史升级原子性与数据保留、拆分期初总额、规则变化与停用阻断、快照冲销、真实来源往来核验、组合结转、未分配明细、权限、并发版本、审计失败回滚、同快照 CSV、桌面完整操作与权限收回。

## 接口与权限

接口放在 `app/finance/auxiliary.py`，前缀为 `/api/v1/finance/auxiliary`。查询和单据操作均使用 ORM 会话；金额按 Decimal 精确到分，CSV 与页面行来自同一读取快照。

| 接口 | 权限与行为 |
| --- | --- |
| `GET /options` | `auxiliary.view`；返回科目、期间、客户/供应商和含停用记录的部门/项目、科目规则。 |
| `POST /items` | `auxiliary.manage`；只建立部门或项目，编码限英文数字、下划线和短横线，填写名称与原因。 |
| `PUT /items/{id}` | `auxiliary.manage`；携带旧版本修改名称或启停，类型和编码固定。 |
| `PUT /policies/{account_id}` | `auxiliary.configure`；携带版本（首次 0）、启用日期、去重必填维度及原因。首次启用不得落入已关闭期间，启用日保存后固定。 |
| `GET /changes` | `auxiliary.view`；返回建立和修改的前后快照、版本、原因及操作者。 |
| `POST /query` | `auxiliary.view`；科目、一个辅助维度、首尾日期；对象 `null` 为全部、`0` 为未分配、正编号为指定对象。 |

余额查询科目或待修改档案不存在返回 404；配置规则的科目不存在或停用，以及版本冲突、无变化、停用辅助对象、不符合规则或不能查询的期初状态返回 409；无权限返回 403，非法输入返回 422。部门和项目的同类编码唯一，审计写入失败会回滚整个操作。

凭证及期初的 `lines[].auxiliary` 只接收 `{kind,id}`；编码和名称由服务端读取，不接受客户端金额或名称快照。单据选项随既有建单权限开放，单独辅助查看权限不包含凭证查看或建单权限。

## 单据、报表与更正

业务生成的 `auxiliary_by_role` 按实际分录角色提交选择。客户/供应商从原订单或收付款关联订单带入，客户端不能替换；部门/项目显式选择。没有往来来源的库存单据不会猜测往来对象。

原始草稿在保存、提交、审核及过账时重新检查当前规则和档案。已过账冲销、系统损益结转保留历史辅助快照，即使对象已停用；后补规则不阻止更正历史账，也不补造历史归属。损益按科目与完整辅助组合分别清零，公司净额为零仍可能生成相抵分录；完整草稿超过现有 100 行上限时明确拒绝，不能截断生成。

拆分期初在试算平衡和公司财务报表中逐行累计；辅助余额按单个维度归组，多维度不会重复计金额。报告包含已确认期初和已过账分录；待确认期初、早于正式启用日期的范围禁止查询。停用对象仍可核对历史余额。来源保留当时编码、名称、完整组合与金额；公司报表和结账归档保留辅助快照，改名不改写归档。历史无辅助记录列为未分配。

桌面“辅助核算”提供余额查询、逐笔明细、独立授权的当前凭证下钻、CSV、档案及规则维护。建单、期初与业务生成复用选择组件；名称由服务端核验。切换账号、撤权和断线清理旧证据，迟到结果不能恢复旧会话数据；保存失败保留表单并提示重新核对。

同账号短暂断线及恢复保留未保存凭证的编号、日期、金额和辅助选择，仅失效在途选项读取并禁用提交；换账号或撤权才清空原草稿。

数据库第 47 版新增五张静态 ORM 表，静态模型共 100 张。旧期初行的编号、金额和科目快照保留；升级移除同科目唯一约束，以允许不同辅助组合，组合重复由服务端核验。旧凭证、期初和已存归档不追加推测辅助信息，旧无辅助来源指纹仍保持兼容。客户端和服务端须同步升级。

历史业务分户应收应付期初由[分户期初](subledger-openings.md)另行提供；银行对账、多币种、附件及实机业务样例验收仍待完成。辅助总账不自动补造业务子账余额。
