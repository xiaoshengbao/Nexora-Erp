# 公司财务报表

本模块提供公司项目/科目配置、资产负债与利润查询、来源核对、CSV、配置审计及关闭期间的不可变归档。桌面入口为财务管理 → 财务报表（`#/workspace/financial-statements`），查看、配置和归档分别授权。

## 范围与金额

单公司、人民币，按公司自行确定的项目与科目关系编制，不预置或声称符合某套法定报表格式。项目编码唯一，名称可配置，所属分组为资产、负债、权益、收入、费用及销售成本。同一科目只能映射到一个项目；资产、负债、权益、收入、费用按类别对应，成本明确选择在制资产或损益费用。备抵与异常负余额如实保留，不按正常余额方向取绝对值。

资产负债表期初为查询开始日以前的正式期初和全部已过账分录，期末包含结束日。权益单列未结转损益，纳入收入、费用和映射为损益的成本余额；不能把已转入权益的盈利重复加入。利润表只取所选日期首尾之间的已过账发生额，不取正式期初或历史发生额。净利润为收入减费用及销售成本，全程用 Decimal 精确到分。

系统损益结转以及关联冲销从利润表发生额排除，仍参与资产负债余额。手工结转须由公司明确列出已过账原始凭证编号，配置审计记录前后范围。含资产或负债业务的混合凭证、业务来源凭证不能标为结转；手工结转成本必须映射为损益费用，不能排除在制资产。仅含损益与权益但未分类的原始凭证会阻止归档，避免手工结转把利润发生额抵成零后被误认为正式结果。

报告返回项目、逐科目贡献、已过账分录来源、正式期初来源、排除标记和未映射非零科目。表格、合计与 CSV 共用读取快照，CSV 对项目名称等输入防公式注入。桌面按项目下钻到科目贡献、正式期初与已过账分录来源；有 `journal.view` 才可继续查看当前凭证、操作记录和生成时的业务/结转证据。归档来源仍为原快照，当前凭证另行标识，不覆盖历史。科目名称、类别和版本纳入服务器来源指纹，核对后修改科目资料会使旧查询失效。

## 配置与归档

第 46 版新增 `financial_statement_policies`、`financial_statement_policy_changes`、`financial_statements` 三张静态 ORM 表，不猜测旧公司的项目映射或补造历史报表。配置保存携带版本和原因；类别、引用、重复映射与手工结转范围在同一写事务核对，审计失败整体回滚。旧版本返回 409。

查询可展示开放期间，明确返回核对中状态和阻止事项。归档要求日期范围是连续、完整且均已结账的期间，正式期初已处理，截至期末不存在未处理凭证，无未映射非零科目，期初和期末资产与负债权益核对相等，损益成本范围与启用的结转配置一致。

归档只接收日期、配置版本、服务器来源指纹和原因，不接受客户端金额、来源或 CSV。服务端重新生成同一快照后核对；配置、凭证及期间状态变化返回 409。来源指纹唯一约束防止并发重复归档；归档不可编辑或删除，保留配置、项目名称、金额、来源、CSV、操作者、时间和依据。后续重开、更正或配置变化不会改写旧归档，新查询须重新核对。

## 后端接口与权限

统一前缀 `/api/v1/finance/statements`：

- GET `/options`：配置、科目、期间和项目分组。
- PUT `/policy`：项目、科目分配、手工结转编号、版本和原因。
- GET `/policy/changes`：完整前后配置审计。
- POST `/query`：开始和结束日期；返回两张报表及同快照来源、核对事项、CSV和指纹。
- POST `/archive`：重算并固定已核对关闭期间的报告。
- GET `/archives`、GET `/archives/{id}`：归档列表和原始快照。

`financial_statement.view/configure/archive` 分别控制查看、配置和归档，默认管理员与财务员拥有；查看不隐含写入。业务查询和写入统一使用 SQLAlchemy ORM，迁移保留必要的底层结构操作。

## 桌面操作与边界

配置编辑允许添加或删除项目、维护名称和分组，并逐科目选择同类别项目；已分配项目的编码锁定，删除项目显式取消相关分配。保存需填写依据，服务端冲突或失败保留输入。手工结转编号严格校验，不重复、不接受小数或混合文本。配置历史完整显示前后项目、科目范围和手工结转编号。

可选完整会计期间或自行选择日期。条件变化立即清除旧报告，迟到响应不会覆盖新选择；换号或撤权清除配置、来源、报表、归档和审计。离线不能读取、导出或写入；只读账号保留查询和原快照导出。归档前在服务器同一写事务重新核对配置、科目、凭证和期间，防止旧金额被固定。

不包括现金流量表、利润分配、税额、法定附注、多币种、合并报表或辅助核算。真实公司期初、会计样例和大规模历史性能仍需验收，单元测试不能替代业务验收。
